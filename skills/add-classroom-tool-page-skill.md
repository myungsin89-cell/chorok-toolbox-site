# 🌿 신규 교실 도구 설명 페이지 생성 및 홈페이지 반영 절차 (스킬 매뉴얼)

이 문서는 '초록덕후의 교실 도구함' 프로젝트에 가이드/바이브코딩이 아닌 일반교실 도구(학급 도구) 설명 페이지를 추가하고, 메인 홈페이지(`index.html`)에 연동하여 정식으로 릴리즈(배포)할 때 AI 코딩 에이전트가 반드시 수행해야 하는 기술적 절차와 체크리스트(스킬 프로토콜)를 정의합니다.

---

## 🚀 1. 신규 도구 설명 HTML 작성 및 레이아웃 규격
새로운 도구 설명 페이지는 `apps/[앱이름].html` 경로에 생성하며, 다음 레이아웃 및 톤앤매너 규격을 엄격하게 준수합니다.

### 🎨 디자인 시스템 준수
- 기존의 초록 시그니처 CSS 변수를 그대로 활용합니다.
  ```css
  :root {
    --green: #15803d;
    --deep: #14532d;
    --bright: #16a34a;
    --mist: #f0fdf4;
    --line: #e3e8e1;
    --line-green: #bbf7d0;
    --ink: #17201a;
    --muted: #66736a;
    --body: #27352b;
  }
  ```
- 가이드 전반의 가독성을 위해 **NanumSquareRound** 및 **Pretendard** 폰트 패밀리를 상속받아 연출합니다.

### 🏷️ 4가지 핵심 뱃지(태그) 규격
- 상단 배너 영역에 도구의 특징을 설명하는 4가지 뱃지를 배치합니다.
  - 예시: `📺 학급 안내 방송`, `💻 바탕화면 설치`, `💾 내 컴퓨터 저장`, `⏰ 타이머/예약`

### ✍️ 사용자 친화적인 우리말 용어 순화 규칙
교사들이 화면 설명이나 작동 원리를 쉽게 이해하고 안심할 수 있도록, 전문 IT 용어 대신 다음 순화 용어를 필수 적용합니다.
1. **PWA 설치형** → **바탕화면 아이콘 설치형** 또는 **바탕화면 앱으로 설치하여 사용하기**
2. **IndexedDB / LocalStorage** → **내 컴퓨터 인터넷 창(브라우저) 내부**
3. **로컬 데이터 보관** → **내 컴퓨터에 안전하게 저장** (개인정보 및 정보 유출 우려를 덜어주는 안심 문구 동반)
4. **크롬 필수 접속 안내**: 기본 설치 및 음성(무료 크롬 내장 TTS 등)의 완벽한 동작을 위해 **반드시 크롬(Chrome) 브라우저로 접속**하여 사용할 것을 주의사항에 강조합니다.
5. **바이브코딩 연계 안내**: 구글 Cloud TTS와 같이 AI API 연동 등으로 고품질 업그레이드를 하는 심화 내용은 **'따라하는 바이브코딩' 강좌**에서 직접 실습하여 개발할 수 있는 부분임을 명확히 안내합니다.

### 📸 필수 이미지 자산 및 라이트박스 규격
- 도구의 주요 기능을 설명하는 4가지 스크린샷 이미지(`apps/images/ss-[앱이름]-[기능].png`)를 매핑합니다.
- 이미지를 클릭했을 때 화면이 어두워지며 원본 이미지가 부드럽게 확대되는 **라이트박스(Lightbox) 인터랙션 팝업**과 단축키(Escape) 종료 기능을 스크립트로 반드시 구현해야 합니다.

## 🔒 2. 메인 페이지(index.html) 반영 및 활성화 규격
설명 페이지 생성이 완료되면 메인 홈페이지(`index.html`)에서 사용자가 접근할 수 있도록 활성화합니다.

1. **준비 중 목록에서 삭제**:
   - `coming-section` 내부의 `coming-grid` 영역에서 해당 도구의 `coming-card` 엘리먼트를 삭제합니다.
2. **도구 카드 추가**:
   - `apps` 클래스를 가진 활성화된 도구 목록 그리드 하단에 새로운 카드 엘리먼트를 추가합니다.
   ```html
   <a class="card" href="apps/[앱이름].html">
     <div class="icon">[아이콘]</div>
     <h3>[도구이름]</h3>
     <p>[순화된 한글 도구 설명]</p>
     <div class="meta">
       <span class="tag">[뱃지1]</span>
       <span class="tag">[뱃지2]</span>
       <span class="tag">[뱃지3]</span>
       <span class="tag">[뱃지4]</span>
     </div>
   </a>
   ```

## 📦 3. 버전 관리 및 릴리즈 프로세스
모든 작업이 완료된 후, 릴리즈를 위해 다음 커맨드를 제안 및 수행합니다.

```powershell
# 1. 변경 및 추가된 파일 스테이징
git add index.html apps/[앱이름].html apps/images/ss-[앱이름]-*

# 2. 규격화된 커밋 메시지 작성
git commit -m "feat: add and link [도구이름] explanation page"

# 3. 원격 저장소 푸시 및 자동 배포
git push origin main
```
