학급일지 만들기

제공받은 학급일지 틀을 커스터마이징해서 나만의 학급일지를 만들어 보세요.

1단계
1 / 4 단계

1단계: 개발 환경 준비하기

안정적인 실습을 위해 크롬 브라우저를 설정하고 모니터 화면을 배치합니다.

  1. 크롬 브라우저 로그인: 내 구글 계정으로 크롬(Chrome) 브라우저에 정상 로그인되어 있는지 확인합니다.
  2. 화면 배치 세팅:
    • 듀얼 모니터: 한쪽 모니터에는 이 가이드 창을, 다른 모니터에는 AI Studio 화면을 띄워 놓고 실습합니다.
    • 단일 모니터: 웹 브라우저 창 2개를 좌우로 반씩 쪼개어 배치해 한눈에 보며 따라 하도록 세팅합니다.
🖥️ 영문 메뉴 번역 팁: 구글 AI Studio는 기본적으로 영문 인터페이스를 제공합니다. 영어 메뉴가 낯설다면 마우스 우클릭 후 [한국어로 번역]을 선택해 쉽게 진행해 보세요!

2단계: 학급일지 템플릿 원클릭 가져오기

초록덕후가 미리 완성해 둔 학급일지 앱 템플릿의 사본을 내 계정으로 가져옵니다.

  1. 아래의 [학급일지 앱 템플릿 복제하기 🌿] 버튼을 클릭하여 공유된 AI Studio 템플릿 페이지를 엽니다.
  2. 새 탭으로 경고창이 열리면, 빨간 테두리로 강조된 [Continue to the app] 버튼을 클릭합니다. (아래 1번 이미지)
  3. 이후 열리는 화면의 우측 상단에 있는 [Remix] (또는 복제) 버튼을 클릭합니다. (아래 2번 이미지)
  4. 클릭 즉시 템플릿 사본이 내 AI Studio 보관함(My apps)에 저장되며, 내가 직접 수정할 수 있는 편집 화면으로 전환됩니다.
① 타사 개발자 안내창 ➡️ [Continue to the app] 누르기
② 우측 상단 ➡️ [Remix] 누르기
학급일지 앱 템플릿 복제하기 🌿

3단계: 한글 채팅으로 조작하기 (바이브코딩)

코드를 만지지 않고, AI Studio 채팅창에서 원하는 바를 한글로 편하게 타이핑하여 기능을 고칩니다.

  1. AI Studio 편집 화면 우측 혹은 하단에 있는 채팅 입력창(Prompt Chat)을 찾습니다.
  2. 마치 카카오톡을 하듯, 내가 필요한 기능을 한글 자연어로 직접 타이핑하여 요청해 봅니다.
  3. 내 대화에 맞춰 AI가 실시간으로 코드를 추가 및 갱신하는 놀라운 '바이브코딩'을 경험해 보세요.
💬 "상단 메뉴에 [성적 관리] 탭도 하나 만들어줘" 💬 "오늘 알림장에 [급식 정보]를 입력할 수 있는 텍스트 상자 추가해줘" 💬 "학생 이름 입력창 바로 옆에 [출석 완료] 체크박스를 달아줘"
💡 Tip: 코딩 문법을 전혀 몰라도 한글 문서를 작성하거나 메신저로 요청하듯 한글로 질문을 던지는 것만으로도 나만의 앱이 완성됩니다. 원하는 모습이 구현될 때까지 AI와 채팅으로 계속 소통해보세요!

4단계: 나만의 주소로 배포 및 결제 설정하기

완성된 학급일지를 인터넷에 배포하여 언제 어디서나 전용 주소로 바로 사용할 수 있도록 호스팅합니다.

  1. AI Studio 편집 화면 우측 상단의 [Publish] (또는 Deploy) 버튼을 누릅니다.
  2. 화면 내에 구글 클라우드 결제 설정을 연동하라는 [결제 수단 등록 (Billing)] 팝업 창이 뜹니다.
  3. 안내에 따라 신용카드 등 구글 계정의 결제 수단 등록 절차를 마칩니다.
  4. 결제 연동이 끝나면 구글이 나만의 [고유한 웹앱 라이브 URL 주소]를 생성해 줍니다. 이 주소를 즐겨찾기(Ctrl+D)하여 실무에 씁니다.
💳 결제 요금 관련 안심 안내:
- 구글 AI Studio를 통해 직접 앱을 배포하고 개인 실무(프로토타입/체험) 용도로 소소하게 사용하는 범위 내에서는 실질적으로 요금이 청구되지 않거나 수 센트 단위의 극소액만 청구됩니다.
- 외부 해킹 위험이 없는 구글의 정식 안전 인프라 서버를 할당받는 인증 절차로 안심하고 신용카드 등록(결제 설정)을 완료하셔도 괜찮습니다!
