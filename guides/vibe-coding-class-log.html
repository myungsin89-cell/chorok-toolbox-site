학급일지 만들기

제공받은 학급일지 틀을 커스터마이징해서 나만의 학급일지를 만들어 보세요.

1단계
1 / 4 단계

1단계: 개발 환경 준비하기

안정적인 실습을 위해 크롬 브라우저를 설정하고 모니터 화면을 배치합니다.

🌿 제공할 기본 '스마트 학급일지' 미리보기
  1. 기본 학급일지 확인: 위 화면은 2단계에서 복제하여 나만의 것으로 가공해 나갈 기본 제공 학급일지 앱의 초기 레이아웃입니다.
  2. 크롬 브라우저 로그인: 내 구글 계정으로 크롬(Chrome) 브라우저에 정상 로그인되어 있는지 확인합니다.
  3. 화면 배치 세팅:
    • 듀얼 모니터: 한쪽 모니터에는 이 가이드 창을, 다른 모니터에는 AI Studio 화면을 띄워 놓고 실습합니다.
    • 단일 모니터: 웹 브라우저 창 2개를 좌우로 반씩 쪼개어 배치해 한눈에 보며 따라 하도록 세팅합니다.
⚠️ 중요 (교육청 계정 접속 차단 안내):
학교/교육청 구글 계정(예: @o365.go.kr, @office.edu 등)은 교육망 보안 및 연령 제한 정책에 의해 AI Studio 서비스 접근이 차단됩니다. 반드시 개인 구글 계정(@gmail.com)으로 로그인을 진행해 주세요.
🖥️ 영문 메뉴 번역 팁: 구글 AI Studio는 기본적으로 영문 인터페이스를 제공합니다. 영어 메뉴가 낯설다면 마우스 우클릭 후 [한국어로 번역]을 선택해 쉽게 진행해 보세요!

2단계: 학급일지 템플릿 원클릭 가져오기

초록덕후가 미리 완성해 둔 학급일지 앱 템플릿의 사본을 내 계정으로 가져옵니다.

  1. 아래의 [학급일지 앱 템플릿 복제하기 🌿] 버튼을 클릭하여 공유된 AI Studio 템플릿 페이지를 엽니다.
  2. 새 탭으로 경고창이 열리면, 빨간 테두리로 강조된 [Continue to the app] 버튼을 클릭합니다. (아래 1번 이미지)
  3. 이후 열리는 화면의 우측 상단에 있는 [Remix] (또는 복제) 버튼을 클릭합니다. (아래 2번 이미지)
  4. Remix 팝업창이 나타나면, 우측 하단에 있는 [Apply] 버튼을 클릭합니다. (아래 3번 이미지)
  5. 클릭 즉시 템플릿 사본이 내 AI Studio 보관함(My apps)에 저장되며, 내가 직접 수정할 수 있는 편집 화면으로 전환됩니다.
① 타사 개발자 안내창 ➡️ [Continue to the app] 누르기
② 우측 상단 ➡️ [Remix] 누르기
③ Remix 확인 팝업창 ➡️ [Apply] 누르기
학급일지 앱 템플릿 복제하기 🌿

3단계: 한글 채팅으로 조작하기 (바이브코딩)

코드를 만지지 않고, AI Studio 채팅창에서 원하는 바를 한글로 편하게 타이핑하여 기능을 고칩니다.

  1. AI Studio 편집 화면의 좌측 또는 중앙 하단에 있는 채팅 입력창(Prompt Chat)을 찾습니다.
  2. 마치 카카오톡을 하듯, 내가 필요한 기능을 한글 자연어로 직접 타이핑하여 요청해 봅니다. (아래 예시 참고)
  3. 내 대화에 맞춰 AI가 실시간으로 코드를 추가 및 갱신하는 놀라운 '바이브코딩'을 경험해 보세요.
💬 "메모장 메뉴 추가해줘. 포스트잇 모양으로 추가할 수 있게 디자인해줘." (추천) 💬 "상단 메뉴에 [성적 관리] 탭도 하나 만들어줘" 💬 "학생 이름 입력창 바로 옆에 [출석 완료] 체크박스를 달아줘"
🌿 AI Studio 채팅창에 한글로 요청을 작성하는 모습
💡 Tip: 코딩 문법을 전혀 몰라도 한글 문서를 작성하거나 메신저로 요청하듯 한글로 질문을 던지는 것만으로도 나만의 앱이 완성됩니다. 원하는 모습이 구현될 때까지 AI와 채팅으로 계속 소통해보세요!
🛠️ 바이브코딩 오류 자가 복구 팁:
- 원격 되돌리기(Undo): AI 채팅 답변 도중 기존 로직이 깨지거나 오작동하면, 당황하지 말고 우측 채팅창에서 이전 질문/답변 블록을 삭제(또는 실행 취소/Undo)하여 직전 성공 시점으로 되돌리세요.
- 점진적 명령: 한 번에 너무 많은 기능 수정을 요구하면 코드가 망가지기 쉽습니다. 기능 한 개씩 순차적으로 바이브코딩하며 매번 작동을 점검하세요.

4단계: 나만의 주소로 배포 및 결제 설정하기

완성된 학급일지를 인터넷에 배포하여 나만의 고유한 사이트 주소를 만들고 배포를 완료합니다.

  1. AI Studio 편집 화면 우측 상단의 [Publish] 버튼을 누릅니다. (아래 1번 이미지)
  2. 배포 안내 팝업이 나타나면 [Get started] 버튼을 클릭합니다. (아래 2번 이미지)
  3. 구글 클라우드 프로젝트 확인 창에서 기본값으로 자동 설정되어 있는 [Default Gemini Project]를 그대로 선택한 상태로 하단의 [Set up billing]을 클릭합니다. (아래 3번 이미지)
  4. 결제 계정 세부정보 등록 팝업창에서 고객 정보(계좌 유형: 개인, 세금 정보: 개인, 주소 등)와 카드 결제 수단을 연동합니다. (아래 4번 이미지)
  5. 결제 등록 완료 후 최종적으로 [나만의 학급일지 is published!] 화면이 나타나 배포가 완료됩니다. 상단의 [Visit] 버튼을 눌러 나만의 라이브 학급일지 웹사이트로 직접 들어가 볼 수 있습니다. 생성된 고유한 웹 주소(App URL)는 꼭 즐겨찾기(Ctrl+D)해두고 사용하세요. (아래 5번 이미지)
  6. 바탕화면에 앱으로 설치(다운로드): 나만의 학급일지 사이트에 접속한 뒤, 크롬 브라우저 주소창 우측 상단에 있는 [모니터와 아래 화살표 모양 아이콘] (앱 설치 버튼)을 클릭하면 PC 바탕화면에 스마트 학급일지가 단독 앱(다운로드 형태)으로 설치됩니다. 매일 주소를 입력할 필요 없이 편리하게 사용해 보세요! (아래 6번 이미지)
💳 빌링(결제) 설정 및 요금 안심 가이드:
- 최초 1회만 연동: 결제 계정 카드 등록은 최초 1회만 해두면 향후 다른 AI 앱 배포 시 번거로운 과정 없이 편리하게 사용할 수 있습니다.
- 무료 요금 한도 적용: 개인 학급 운영 등 소규모 프로토타입 범위 내에서는 구글 클라우드가 매월 제공하는 기본 무료량(Gemini 1.5 Flash 기준 15 RPM / 1,500 RPD) 내에 충분히 머물기 때문에 요금이 실질적으로 청구되지 않아 전혀 걱정하지 않으셔도 좋습니다.
- 결제 등록을 원치 않으시는 경우 (우회법): 신용카드 정보 등록이 어렵거나 꺼려지신다면, 배포(Publish) 절차를 생략하고 AI Studio 우측의 [Preview] 테스트 화면을 전체화면으로 넓혀서 즉석에서 학급 관리에 그대로 활용하셔도 무방합니다.
💡 주소창 우측에 다운로드(설치) 아이콘이 안 보일 때 우회 설치법:
웹 통신 규격에 따라 크롬 주소창에 다운로드(PWA) 아이콘이 나타나지 않을 수 있습니다. 이때는 크롬 브라우저 우측 상단 **[점 3개 메뉴(⋮)] -> [저장 및 공유] -> [바로가기 만들기]**를 클릭하신 뒤, **[창으로 열기] 옵션을 꼭 체크**하고 만들기를 누르면 바탕화면에 동일하게 설치 형태로 사용하실 수 있습니다.
① 우측 상단 ➡️ [Publish] 버튼 클릭
② 시작 팝업 ➡️ [Get started] 클릭
③ 프로젝트 ➡️ [기본 프로젝트] 선택 후 [Set up billing] 클릭
④ 결제 등록 ➡️ 고객 정보 및 신용카드 연동하기
⑤ 완료 ➡️ [Visit]을 눌러 홈페이지 접속 & 주소 기억하기
⑥ 다운로드 ➡️ 주소창 우측의 [앱 설치] 아이콘 클릭하여 바탕화면에 추가
