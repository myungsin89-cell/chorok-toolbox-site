동학년 협업 게시판의 주요 기능들을 살펴보고 내 보관함에 복제합니다.

📋 1) 공지사항 게시 및 확인 동학년 중요한 긴급 공지를 실시간으로 등록하고 한눈에 함께 확인합니다. (아래 1번 이미지)
📅 2) 학년 달력 공유 (일정 추가) 학년 공동 행사, 수행평가 일정, 현장체험 등 학년 스케줄을 캘린더로 공동 관리합니다. (아래 2번 이미지)
🗳 3) 의견 수렴 (투표하기) 의결이 필요하거나 빠른 의견 취합이 필요할 때 간편히 무기명/기명 투표를 개설합니다. (아래 3번 이미지)
🖨 4) 기자재 및 특별실 예약 학년 공용 교구나 컴퓨터실 사용 일정이 겹치지 않게 실시간 예약 현황을 관리합니다. (아래 4번 이미지)
🛡 데이터 삭제 및 관리를 위한 [관리자 모드]:
- 상단 메뉴의 [관리자] 탭을 클릭하여 게시판의 모든 등록 데이터(공지, 일정, 투표, 예약)를 삭제 및 초기화 관리할 수 있습니다. (아래 5번 이미지)
- 초기 관리자 비밀번호는 0000으로 세팅되어 있습니다.
① [공지사항] : 동학년 중요한 소식 공유 게시판
② [학년 달력] : 동학년 주요 행사 및 일정 등록 캘린더
③ [의견 수렴] : 안건 개설 및 실시간 투표 취합
④ [기자재 예약] : 특별실 및 공용 기자재 예약 현황판
⑤ [관리자 모드] : 상단 관리자 탭을 통한 글 삭제 및 리셋 기능 (비밀번호: 0000)
  1. 개인 구글 계정 로그인: 구글 AI Studio를 사용하기 위해 **반드시 개인용 구글 계정(@gmail.com)**으로 크롬 브라우저에 로그인합니다.
  2. 아래의 [동학년 게시판 템플릿 복제하기 🌿] 버튼을 클릭하여 공유된 AI Studio 템플릿 페이지를 엽니다.
  3. 경고창 통과 : 우측 상단 [Remix] 클릭 : 팝업 우측 하단 [Apply]를 클릭하여 내 보관함에 복사본을 가져옵니다.
⚠ 중요 (교육청 계정 접속 차단 안내):
학교/교육청 구글 계정(예: @o365.go.kr, @office.edu 등)은 교육망 보안 및 연령 제한 정책에 의해 AI Studio 서비스 접근이 차단됩니다. 반드시 개인 구글 계정(@gmail.com)으로 실습해 주세요.

2단계: 게시판 복제 및 실시간 공유 서버 연결하기

제공된 템플릿의 사본을 내 계정으로 가져온 뒤, 동학년 선생님들과 데이터를 실시간 공유할 수 있게 서버(데이터베이스)를 연동합니다.

💳 서버 및 배포 요금 안심 가이드 (걱정 마세요!):
- 데이터베이스 평생 무료: 본 실습에서 연동할 파이어베이스(Firebase) 데이터베이스는 무료 등급(Spark 요금제) 한도 내에서 작동하여 요금이 발생하지 않습니다.
- 배포 시 카드 등록 안내: 마지막 4단계 배포(Publish) 과정에서 구글 클라우드 플랫폼(GCP) 계정 인증 및 본인 확인을 위해 카드 등록 절차가 요구됩니다.
- 텍스트 위주 운영으로 요금 걱정 제로: 이 게시판은 고용량 사진/영상이 아닌 텍스트 위주의 데이터(공지사항, 달력, 예약 등)만 주고받기 때문에 데이터 소모량이 극히 적습니다. 동학년 선생님들이 일상적인 업무 협업용으로 사용하시는 범위 내에서는 구글이 매월 제공하는 무료 제공량을 초과할 일이 거의 없으므로 청구 요금 걱정 없이 안심하고 사용하셔도 좋습니다!
  1. 1단계의 [동학년 게시판 템플릿 복제하기 🌿] 버튼을 눌러 새 창이 열리면, 우측 상단의 [Remix] 버튼을 누릅니다. (아래 1번 이미지) 이후 팝업창에서 [Apply]를 클릭합니다.
  2. 화면에 Remix: Set up OAuth 팝업창이 나타나면, 빨간 테두리로 강조된 [Let's do it] 버튼을 클릭하여 구글 클라우드 권한을 연동합니다. (아래 2번 이미지)
  3. 리믹스가 완료되어 편집 화면이 나타나면, 화면 우측 안내 카드의 2번 박스에 있는 [클릭으로 즉시 복사] 버튼을 클릭하여 명령어를 복사합니다. (아래 3번 이미지)
    • 복사되는 명령어: 파이어베이스 데이터베이스 세팅해줘!
  4. AI Studio 편집 화면의 좌측 하단에 있는 채팅창(Prompt Chat)에 복사한 명령어를 붙여넣고 엔터(전송)를 누릅니다. (아래 3번 이미지의 2번 영역)
  5. AI 에이전트가 데이터베이스를 자동으로 연동하는 과정을 마친 뒤, 화면 중앙이 성함을 입력하는 일반 로그인 첫 화면으로 자동으로 바뀌면 서버 연결이 성공적으로 끝난 것입니다! (아래 4번 이미지)
① 우측 상단 : [Remix] 버튼 누르고 [Apply] 승인하기
② OAuth 연동 창 : [Let's do it] 클릭하여 권한 부여
③ 자동 연동 명령어 : 복사하여 좌측 하단 채팅창에 입력 후 엔터
④ 연동 완료 : 화면 중앙이 일반 로그인(성함 입력) 상태로 바뀌면 연결 성공

3단계: 나만의 게시판으로 맞춤 수정하기 (바이브코딩 체험)

서버 연동이 완료된 게시판에 로그인하여 진입한 뒤, 한글 채팅으로 원하는 새로운 기능이나 메뉴 수정을 가볍게 지시해 봅니다.

  1. 서버 연동 성공 후 나타난 로그인(성함 입력) 화면에서 본인의 성함을 입력하고 [동학년 소통 시작하기]를 클릭합니다. (아래 1번 이미지)
  2. 게시판 메인으로 성공적으로 진입하면, 좌측 하단의 채팅창(Prompt Chat)에 원하는 맞춤형 추가 기능을 한글로 자유롭게 요청해 봅니다. (아래 2번 이미지)
💬 "동학년 선생님들과 공유할 수 있는 메모장 메뉴를 만들어줘" (추천 예시)
💬 "상단 타이틀 문구를 '2026학년도 5학년 동학년 게시판 🌿'으로 수정해줘."
💬 "메뉴 탭 중에서 [기타 자료] 이름을 [행정 업무]로 변경해줘."
① 본인 성함 입력 : [동학년 소통 시작하기] 버튼 클릭
② 게시판 진입 : 좌측 하단 채팅창에 원하는 추가 기능 및 디자인 조작 입력
💡 바이브코딩 오류 자가 복구 팁:
- 원격 되돌리기(Undo): AI 채팅 답변 도중 기존 로직이 깨지거나 오작동하면, 당황하지 말고 우측 채팅창에서 이전 질문/답변 블록을 삭제(또는 실행 취소/Undo)하여 직전 성공 시점으로 되돌리세요.
- 점진적 명령: 한 번에 너무 많은 기능 수정을 요구하면 코드가 망가지기 쉽습니다. 기능 한 개씩 순차적으로 바이브코딩하며 매번 작동을 점검하세요.

4단계: 배포하고 바탕화면 설치 & 동학년 공유하기

나만의 주소로 게시판을 업로드하여 동학년 선생님들과 고유 주소를 공유하고 협업을 시작합니다.

  1. AI Studio 우측 상단 [Publish] 클릭 ➡️ [Get started] 클릭 (아래 1, 2번 이미지)
  2. 구글 클라우드 프로젝트 확인창에서 기본값인 [Default Gemini Project]를 선택한 채 [Set up billing]을 클릭하고 결제 카드를 최초 1회 연동합니다. (아래 3, 4번 이미지)
  3. 최종 배포가 완료되면 상단의 [Visit] 버튼을 눌러 나만의 실시간 동학년 게시판 사이트로 접속합니다. (아래 5번 이미지)
  4. 접속한 상태에서 크롬 주소창 우측 상단의 [앱 설치(다운로드) 아이콘]을 클릭하여 PC 바탕화면에 단독 앱으로 설치합니다. (아래 6번 이미지)
  5. 설치가 완료되면 PC 바탕화면에 예쁜 [동학년 게시판] 아이콘이 생성됩니다. 다음 접속부터는 이 바탕화면 아이콘만 더블클릭하면 브라우저 없이 즉시 바로 열립니다! (아래 7번 이미지)
  6. 완성된 고유 사이트 주소(App URL)를 복사하여 **동학년 메신저나 단톡방에 공유**해 실시간 협업을 시작하세요!
💳 빌링(결제) 설정 및 요금 안심 가이드:
- 최초 1회만 연동: 결제 계정 카드 등록은 최초 1회만 해두면 향후 다른 AI 앱 배포 시 번거로운 과정 없이 편리하게 사용할 수 있습니다.
- 무료 요금 한도 적용: 개인 학급 운영 등 소규모 프로토타입 범위 내에서는 구글 클라우드가 매월 제공하는 기본 무료량(Gemini 1.5 Flash 기준 15 RPM / 1,500 RPD) 내에 충분히 머물기 때문에 요금이 실질적으로 청구되지 않아 전혀 걱정하지 않으셔도 좋습니다.
- 결제 등록을 원치 않으시는 경우 (우회법): 신용카드 정보 등록이 어렵거나 꺼려지신다면, 배포(Publish) 절차를 생략하고 AI Studio 우측의 [Preview] 테스트 화면을 전체화면으로 넓혀서 즉석에서 학급 관리에 그대로 활용하셔도 무방합니다.
🌿 번거로운 재로그인 방지 (성함 정보 자동 유지):
처음 한 번만 성함을 입력하여 소통을 시작해 두면, 성함 정보가 선생님의 로컬 컴퓨터 브라우저 저장소(IndexedDB)에 안전하게 자동 보관됩니다. 브라우저 임시 데이터를 강제로 포맷하지 않는 한, **바탕화면 아이콘을 더블클릭할 때마다 성함 재입력 없이 바로 메인 게시판으로 자동 로그인 진입**합니다.
💡 주소창 우측에 다운로드(설치) 아이콘이 안 보일 때 우회 설치법:
웹 통신 규격에 따라 크롬 주소창에 다운로드(PWA) 아이콘이 나타나지 않을 수 있습니다. 이때는 크롬 브라우저 우측 상단 **[점 3개 메뉴(⋮)] -> [저장 및 공유] -> [바로가기 만들기]**를 클릭하신 뒤, **[창으로 열기] 옵션을 꼭 체크**하고 만들기를 누르면 바탕화면에 동일하게 설치 형태로 사용하실 수 있습니다.
