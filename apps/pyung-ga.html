모둠 평가 앱

🚀 모둠 평가 앱 사용하기

발표, 역할극, 모둠 토론 평가를 실시간으로. 학생들의 의견 취합부터 채점 내역 확인까지 한 번에 정리합니다.

무엇을 하나요?

발표나 역할극 수업 시 동료 평가를 실시간 대시보드로 쉽게 관리하기 위해 만든 앱입니다.

  • 🎯 평가 기준 커스텀 — 3단계 기호(◎/○/△) 채점 및 5점 만점 별점 선택. 모둠별 질문과 전체 공통 질문(예: 베스트 학생 추천, 수업 소감)을 자유롭게 생성합니다.
  • 📱 편리한 학생 참여 — 회원가입 없이 4자리 간편 코드로 입장하며, 자기 모둠을 선택하고 입장하면 본인 모둠의 평가 카드는 자동으로 숨겨집니다.
  • 📊 실시간 상세 대시보드 — 실시간 제출율을 확인하고, 모둠 카드 클릭 시 타 모둠이 평가한 기준별 상세 채점 내역과 주관식 피드백을 질문별로 모아 실시간으로 역추적합니다.

▲ 🛠️ 평가 생성 — 제목, 모둠 수, 채점 척도, 모둠별/전체대상 질문 목록을 커스텀 정의합니다.
▲ 📱 우리 모둠 선택 — 학생 로그인 없이 모둠을 골라 중복 내역을 조회하고 바로 평가를 시작합니다.
▲ 📝 모둠별 및 공통 질문 작성 — 모둠별 척도/주관식 채점과 전체 공통 피드백을 분리하여 작성합니다.
▲ 📊 상세 대시보드 — 득표 합계, 평가 모둠별 세부 점수표, 서술 질문별 모아보기 피드백을 실시간 확인합니다.

사용 안내

📌 시작하기 전에

크롬, 엣지, 웨일 등 최신 웹 브라우저에서 실행 및 실시간 통신을 권장합니다.

1단계 — 평가 개설 (교사용)

앱에 접속한 뒤 '새로운 평가 만들기'에서 평가 제목과 총 모둠 수를 정하고, 모둠별 주관식 문항 및 공통 주관식 문항을 필요한 만큼 개설하여 4자리 고유 코드를 발급받습니다.

2단계 — 우리 모둠 선택 및 입장 (학생용)

학생들은 발급받은 코드 4자리를 입력하고 입장한 뒤, 본인이 속한 모둠을 고릅니다. 기존에 작성한 내용이 있으면 자동으로 폼에 불러오며 수정 및 재제출이 가능합니다.

3단계 — 동료 채점 진행

각 모둠의 발표나 역할극을 보며 터치로 손쉽게 ◎○△ 또는 별점을 입력하고, 서술형 의견을 작성하여 제출합니다.

⚡ 4단계 — 실시간 수업 피드백 루틴 (수업 적용)

발표가 끝나면 교실 TV에 대시보드 화면을 띄웁니다. 점수 카드를 클릭해 **어느 모둠이 어떤 기준에서 감점/가점했는지 세부 점수표**와 주관식 의견을 즉석에서 공유하며 피드백을 나눕니다.

☁️ 실시간 저장 및 업데이트

모든 데이터는 Firebase 실시간 데이터베이스에 업로드되어 실시간으로 업데이트되며, 학생들이 평가 도중 나가거나 브라우저를 새로고침해도 작성 중이던 답변 정보가 안전하게 임시 저장되어 복원됩니다.

📌 꼭 알아두세요

  • 실시간 통신 — 학생들의 신속한 피드백 반영을 위해 Firebase Realtime Database와 실시간 연동되어 작동합니다.
  • 동일 평가 중복 제출 방지 — 동일한 모둠이 여러 번 평가를 제출하더라도 기존 데이터가 수정 업데이트되어 최종 1개의 평점만 계산되어 공정합니다.
  • 학교 수업 맞춤형 도구 — 교사가 평가 질문을 완전히 자유롭게 커스텀할 수 있어 발표, 토론, 역할극, 체육 활동 등 다양한 모둠 수업에 적용하기 좋습니다.
