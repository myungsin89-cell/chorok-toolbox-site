모둠 평가 앱

🚀 모둠 평가 앱 사용하기

발표, 역할극, 모둠 토론 평가를 실시간으로. 학생들의 의견 취합부터 채점 내역 확인 및 엑셀 다운로드까지 한 번에 정리합니다.

무엇을 하나요?

발표나 역할극 수업을 할 때, 학생들이 서로를 실시간으로 평가하고 결과를 바로 확인하기 위해 만든 앱입니다.

  • 🎯 우리 반 맞춤 질문 — 기호(◎/○/△)나 별점으로 점수를 매기고, 모둠별 개별 질문과 전체 공통 질문을 자유롭게 만듭니다.
  • 📱 클릭 한 번으로 로그인 — 회원가입이 필요 없습니다. 4자리 코드를 입력하거나, 링크 클릭 한 번으로 자동 로그인하여 쉽게 참여합니다.
  • 📊 실시간 확인과 엑셀 저장 — 학생들이 제출한 점수와 의견을 실시간 대시보드로 확인하고, 단 한 번의 클릭으로 깔끔하게 정리된 엑셀 파일을 내려받습니다.
  • 💾 최근 목록과 내역 지우기 — 내가 최근에 만든 평가 방 목록이 홈 화면에 저장되어 빠르게 재입장할 수 있고, 필요 없는 내역은 언제든 목록에서 지울 수 있습니다.

화면 미리보기

💡 이미지를 클릭하면 크게 볼 수 있습니다.

▲ 📱 메인 화면 — 평가 참여, 방 생성, 대시보드 확인 등 원하는 작업을 선택하며, 최근 개설한 평가 목록 확인과 앱 설치가 가능합니다.
▲ 🛠️ 평가 생성 — 제목, 모둠 수, 채점 기준, 질문을 입력해 평가 방을 개설합니다.
▲ 📝 학생 평가 화면 — 발표를 관람하며 별점/기호를 매기고 잘한 점과 피드백을 남깁니다.
▲ 📊 실시간 대시보드 — 실시간 제출 현황, 세부 점수 및 의견 취합 결과를 확인하고 엑셀로 내려받습니다.

사용 안내

📌 시작하기 전에

인터넷이 연결된 환경에서 크롬, 엣지, 웨일 등 최신 웹 브라우저를 사용해 주세요.

1단계 — 평가 방 만들기 (선생님)

앱에 접속해 '새로운 평가 만들기'를 누릅니다. 제목, 모둠 수, 채점 기준, 질문을 적어 평가 방을 개설하고 4자리 고유 코드를 발급받습니다.

2단계 — 링크 공유 및 입장 (학생)

학생들에게 발급된 4자리 코드를 알려주거나, 화면에 표시된 자동 로그인용 주소(예: ?code=1234가 포함된 링크)를 복사해 공유해주시면 코드 입력 없이 터치 한 번으로 간편하게 로그인할 수 있습니다.

3단계 — 다른 모둠 점수 주기 (학생)

본인이 속한 모둠을 선택하고 입장하여, 발표를 보며 점수(기호 또는 별점)를 누르고 잘한 점이나 피드백 의견을 입력해 전송합니다. (내가 속한 모둠은 점수를 줄 수 없도록 화면에 나타나지 않습니다.)

⚡ 4단계 — 실시간으로 피드백 나누기 (수업 중)

발표가 끝나면 교실 TV 화면에 대시보드를 띄웁니다. 모둠 카드나 세부 점수표를 클릭하여 어느 모둠이 어떤 기준에서 점수를 주었는지, 어떤 글 피드백을 남겨주었는지 즉석에서 함께 공유하며 피드백을 나눕니다.

☁️ 엑셀 저장 및 최근 목록 관리 (수업 후)

수업이 끝나면 대시보드 화면의 '통합 엑셀 다운로드' 버튼을 눌러 점수표와 의견 글이 각각 정리된 파일을 내려받아 보관합니다. 홈 화면에서는 최근에 만든 방 목록을 보고 언제든지 대시보드로 다시 진입하거나, 필요 없어진 방은 ❌ 버튼으로 목록에서 지웁니다.

📌 꼭 알아두세요

  • 인터넷 연결 필수 — 학생들의 피드백을 실시간으로 취합하고 화면에 중계하기 위해 인터넷 연결이 필요합니다.
  • 실수 수정 및 중복 방지 — 동일한 학생(모둠)이 새로고침 등으로 여러 번 전송하더라도, 가장 마지막에 입력해 제출한 내용 1개만 반영되니 안심하고 다시 보내도 됩니다.
  • 최근 만든 평가 보관 — 내가 만든 방 목록은 인터넷 창에 임시로 저장(localStorage)됩니다. 인터넷 사용 기록이나 캐시를 지우면 리스트에서 사라질 수 있지만, 평가는 4자리 코드로 언제든지 다시 열 수 있습니다.
