학급 방송앱

🚀 사용하기

대사를 입력하면 실시간 음성(TTS)으로 변환해 말해주는 스마트 방송 도구입니다. 매일 반복하는 말들을 방송으로 예약해서 선생님의 소중한 목을 보호하세요.

무엇을 하나요?

  • 즉석 음성 방송(TTS) — 안내할 대사를 입력창에 적기만 하면, 즉시 기계 음성(TTS)으로 변환되어 교실 스피커로 실시간 송출됩니다.
  • 방송 예약 (날짜/시간별) — 지정한 날짜와 시간에 맞추어 필요한 안내 방송이 자동으로 흘러나오도록 타임라인 스케줄을 예약합니다.
  • 타이머 기반 방송 (전체화면 지원) — 방송 대사를 적어두고 5분 뒤, 10분 뒤처럼 설정한 타이머가 완료되면 알림음과 함께 자동으로 방송이 시작되게 예약합니다. 타이머 예약 후 [전체화면] 버튼을 누르면 큰 전체화면으로 시간이 실시간으로 줄어들며, 시간이 끝나면 자동으로 방송이 흘러나오는 기능이 제공됩니다.
  • 자주 쓰는 문구 즐겨찾기 — "정리정돈을 시작하세요" 같이 매일 반복적으로 쓰이는 멘트들은 즐겨찾기 카드로 만들어 원클릭으로 송출합니다.

이렇게 사용해요

  • 1. 대사 입력 및 즉석 방송 — 방송하고 싶은 내용을 텍스트 입력창에 자유롭게 작성한 뒤, 방송 버튼을 클릭하면 즉시 로컬 음성으로 송출됩니다.
  • 2. 반복 안내 즐겨찾기 카드로 등록 — 자주 내보내는 방송 멘트는 즐겨찾기 카드(메인 화면 버튼)로 등록해 두어, 매번 입력할 필요 없이 버튼 한 번만 눌러 송출합니다.
  • 3. 타이머 기반 예약 방송 실행 (전체화면 타이머) — 모둠 활동이나 쉬는 시간 등을 조율할 때, 설정한 타이머가 완료되는 시점에 맞추어 자동으로 대사가 방송되게 합니다. 타이머를 예약하고 [전체화면] 버튼을 누르면 화면 가득 시간이 실시간으로 줄어들며, 시간이 끝나면 자동으로 방송이 송출됩니다.
  • 4. 정기 안내 방송 스케줄링 — 아침 조회 시간, 요일별 종례 전 등 지정된 일정과 요일별 타이밍에 정기 예약 방송 목록을 관리하여 학급 운영을 자동화합니다.

AI 음성 연결로 더 세련된 방송 만들기

💡 기본 음성 안내 (크롬 브라우저 무료 TTS 이용)

이 앱은 기본적으로 크롬(Chrome) 브라우저가 내장하고 있는 무료 시스템 음성(TTS)을 사용하여 방송을 내보냅니다. 따라서 최적의 음성 작동을 위해 반드시 크롬 브라우저로 접속해 주시기 바랍니다.

💡 구글 Cloud TTS 연계 (바이브코딩 강좌 안내)

기본 무료 음성보다 더 자연스럽고 세련된 AI 성우 목소리(구글 Cloud TTS)로 업그레이드하고 싶다면, '따라하는 바이브코딩' 강좌를 보며 직접 코드를 수정하고 연동해볼 수 있습니다.

화면 미리보기

💡 이미지를 클릭하면 크게 볼 수 있습니다.

▲ 메인 화면: 대사 입력창, 음성 방송 송출 및 즉각적인 로컬 TTS 방송 작동 상태를 제어하는 기본 화면입니다.
▲ 방송중 화면: 설명을 작성한 대사나 예약된 방송이 다음과 같은 화면으로 방송됩니다.
▲ 예약된 화면: 날짜, 시간, 요일별 타임라인 스케줄이 연동된 정기 안내 방송 예약 리스트 관리 화면입니다.
▲ 설정 화면: 고품질 구글 Cloud TTS API 연동, 기기 음성 설정 및 방송 환경 세부 설정 패널입니다.

설치와 데이터 보관 안내

📌 크롬 브라우저로 바탕화면 아이콘 설치하기

기본 설치 버전은 반드시 크롬(Chrome) 브라우저로 접속하여 사용해 주세요. 크롬 주소창 오른쪽에 있는 [앱 설치] 버튼을 누르면, 컴퓨터 바탕화면에 바로가기 아이콘을 만들어 두고 일반 프로그램처럼 편리하게 실행할 수 있습니다.

💾 내 컴퓨터에 안전하게 저장

내가 등록한 안내 방송 예약 내용이나 자주 쓰는 즐겨찾기 문구는 인터넷 서버로 전송되지 않고, 오직 **내가 쓰는 컴퓨터의 인터넷 창(브라우저) 내부**에만 저장됩니다. 개인정보나 학급 정보 유출 걱정 없이 안심하고 쓰셔도 됩니다.
