# [인디광장-팁&강좌 업로드용 초안]

**제목:** 매일 똑같은 잔소리는 AI에게! 선생님 목소리를 지켜주는 '학급 방송앱' 🌿

---

선생님들, 교실에서 하루에 똑같은 안내 멘트를 몇 번이나 반복하시나요?

*"정리정돈 시간입니다. 제자리에 정리하세요."*
*"모둠 활동 시간 5분 남았습니다."*
*"쉬는 시간이 끝났으니 자리에 앉아주세요."*

매일 같은 이야기를 목청 높여 반복하다 보면 목이 아프고 금방 피곤해지곤 합니다. 

*'매번 똑같이 반복하는 말들을 AI가 대신 방송해 줄 수는 없을까?'*
이 작은 고민에서 출발해, **선생님들의 소중한 목소리(성대)를 보호하기 위한 '학급 방송앱'**을 만들어 공유합니다. 🌿 

가입이나 로그인 필요 없이 접속 즉시 무료로 사용해 보실 수 있습니다.

---

### 📺 학급 방송앱은 무엇을 하나요?

- 📢 **즉석 음성 방송 (TTS):** 안내할 대사를 텍스트 입력창에 적기만 하면, 크롬 내장 음성 엔진이 생각보다 훨씬 또렷하고 자연스러운 목소리로 교실 스피커에 실시간 송출해 줍니다. (귀에 거슬리는 차가운 기계음이 아니에요!)
- ⏰ **전체화면 타이머 방송:** 모둠 활동이나 쉬는 시간을 조율할 때 대사와 시간을 설정해 두면, 타이머가 만료되는 순간 알림음과 함께 자동으로 방송이 나갑니다. (전체화면 모드를 띄워두면 칠판 대용으로도 훌륭합니다!)
- 📅 **정기 안내 방송 예약:** 아침 조회, 종례 전 등 지정된 일정과 요일별 타이밍에 맞춰 정기 예약 방송 목록을 스케줄링하여 학급 운영을 자동화합니다.
- ⭐ **자주 쓰는 문구 즐겨찾기:** "정리정돈을 시작하세요"처럼 매일 쓰는 문구는 즐겨찾기 카드로 만들어 두어 마우스 클릭 한 번으로 바로 송출할 수 있습니다.

---

### 📸 미리보기 화면 (스크린샷 첨부 위치)

- **📸 [스크린샷 삽입 위치 01] 메인 화면:** 안내 대사를 적고 즉시 방송을 제어하는 메인 화면입니다.
- **📸 [스크린샷 삽입 위치 02] 방송중 화면:** 예약된 대사가 큰 글씨 카드와 함께 실제 스피커로 방송되는 화면입니다.
- **📸 [스크린샷 삽입 위치 03] 방송 예약 화면:** 요일/날짜/시간별 정기 안내 방송 스케줄을 추가하고 관리하는 캘린더 화면입니다.
- **📸 [스크린샷 삽입 위치 04] 설정 및 구글 TTS 화면:** 고품질 구글 AI 성우 목소리 연동 및 세부 음성 속도를 조절하는 설정 창입니다.

---

### 🛠️ 어떻게 사용하나요?

1. **인터넷 브라우저로 즉시 실행:** 회원가입이나 로그인 없이 아래 링크에서 바로 텍스트를 입력해 방송해 보세요!
   *(⚠️ **크롬 브라우저 필수:** 크롬의 고품질 내장 TTS 기능으로 방송이 나갑니다. 따라서 앱을 열어 사용하실 때는 **반드시 크롬(Chrome) 브라우저**로 접속해 주세요!)*
2. **바탕화면에 프로그램으로 설치:** 크롬 주소창 우측의 **[앱 설치(다운로드)]** 아이콘을 누르면, 컴퓨터 바탕화면에 바로가기 앱으로 설치되어 일반 프로그램처럼 실행할 수 있습니다.
   *(설치 버튼이 안 보이면: **크롬 우측 상단 점 3개 ➡️ 저장 및 공유 ➡️ 바로가기 만들기 (창으로 열기 체크)**)*
3. **내 컴퓨터에 안전하게 보관:** 등록한 예약 정보나 즐겨찾기 문구는 인터넷 서버로 전송되지 않고 **오직 선생님 컴퓨터 브라우저 내부(LocalStorage)에만 저장**되므로 개인정보 유출 우려가 전혀 없습니다.

### 💡 구글 Cloud TTS 연계로 고품질 목소리 업그레이드 안내
- 이 앱은 기본적으로 크롬 브라우저가 제공하는 무료 시스템 음성(Chrome 내장 TTS)을 사용하며, 생각보다 발음이 매우 깨끗합니다.
- 만약 이에 만족하지 않고 **전문 AI 성우 수준의 고품질 목소리(구글 Cloud TTS)**로 더욱 자연스럽게 업그레이드하고 싶으시다면, **추후 '따라하는 바이브코딩' 강좌**를 통해 구글 Cloud TTS API 키를 직접 코드 한 줄로 연결하는 방법을 쉽게 가이드해 드릴 예정입니다!
