# [인디광장-팁&강좌 업로드용 초안 - 간결 버전]

**제목:** [왕초보 바이브코딩#2] 10분 만에 실시간 공유되는 동학년 게시판 만들고 배포하기 🌿

---

선생님들, 학기 중에 동학년 선생님들과 일정이나 업무 조율하시느라 번거로우셨던 적 많으시죠?

*"오늘 4교시에 특별실(과학실/체육관) 쓰시는 분 계시나요?"*
*"이번 주 수행평가나 학년 일정 변경된 것 있나요?"*
*"공용 교구 예약 캘린더가 있으면 좋겠는데…"*

매번 단톡방이나 메신저로 묻고 답하느라 번거로우셨다면, 이번 기회에 **우리 학년만의 실시간 소통 게시판을 10분 만에 직접 만들어보세요!**

기본적인 기능이 전부 준비된 뼈대(템플릿)를 무료로 제공해 드리니, 코딩을 전혀 몰라도 클릭 몇 번과 말 한마디면 완성됩니다. 🌿

---

### 💡 잠깐! '실시간 공유 서버'가 대체 뭔가요?
지난 1탄(학급일지)에서는 데이터를 내 컴퓨터 브라우저에만 저장했기 때문에 나 혼자만 볼 수 있었습니다. 
하지만 이번 동학년 게시판은 다른 선생님들과 실시간으로 데이터를 주고받아야 하죠? 

이렇게 여러 사람이 함께 데이터를 보관하고 공유하는 공간을 **'서버(데이터베이스)'**라고 합니다. 
어렵게 느껴지시겠지만 걱정 마세요! 구글 AI Studio를 활용하면, **한글로 말 한마디만 하면 AI가 서버를 알아서 한 줄로 뚝딱 연결해 줍니다.**

---

### 📦 기본 템플릿에는 어떤 기능이 들어있나요?
제공되는 기본 템플릿은 그대로 가져가서 바로 써도 될 만큼 학교 현장 맞춤형 기능들이 다 채워져 있습니다.
- 📢 **공지사항:** 동학년 긴급 공지 실시간 등록 및 확인
- 📅 **학년 달력:** 수행평가, 행사 등 공동 일정 캘린더 관리
- 🗳️ **의견 수렴:** 무기명/기명 신속 투표 기능
- 🏫 **기자재/특별실 예약:** 체육관, 과학실, 공용 교구 실시간 예약 관리
- 🔒 **데이터 관리자 페이지:** 잘못 올린 내용을 정리할 수 있는 관리자 창 (기본 비밀번호: `0000`)

### 🛠️ 동학년 게시판 만들기 (요약 3단계)

**1. 원클릭 복제하기 (Remix)**
- 아래 템플릿 복제 링크에 접속해 우측 상단 **[Remix] ➡️ [Apply]**를 누릅니다.
- 🔗 [AI Studio 동학년 게시판 템플릿 링크](https://ai.studio/apps/dcd00c82-5d1d-494c-912f-bea1368a4ddc)
- 팝업창이 뜨면 **[Let's do it]**을 클릭해 구글 클라우드 권한을 연동해 줍니다.
- **📸 [스크린샷 삽입 위치 01]** (Remix 버튼 및 OAuth 권한 연동 팝업 화면)

**2. 실시간 서버 연결하기 (바이브코딩)**
- 리믹스 완료 후 화면 좌측 하단의 채팅창(Prompt Chat)에 아래 명령어 한 줄을 입력하고 전송합니다.
- 💬 *"파이어베이스 세팅하고 프로젝트 파일 바탕으로 보안규칙도 즉시 배포해줘!"*
- AI가 작업을 마친 뒤, 화면 중앙이 이름을 입력하는 로그인 첫 화면으로 바뀌면 서버 연동 성공입니다!
- **📸 [스크린샷 삽입 위치 02]** (채팅창 명령 입력 및 로그인 첫 화면 전환 화면)

**3. 나만의 주소로 배포하고 바탕화면 설치하기 (Publish)**
- 성함을 입력하고 게시판에 진입한 뒤, 원하는 부분(메뉴 이름, 타이틀 문구 등)을 대화로 수정합니다.
  (예: 💬 *"상단 타이틀 문구를 '5학년 동학년 게시판'으로 변경해줘"*)
- 우측 상단 **[Publish] ➡️ [Default Gemini Project] ➡️ 결제 등록**을 마쳐 고유 웹 주소(URL)를 받습니다.
- 생성된 주소로 접속한 뒤 크롬 주소창 우측의 **[앱 설치(다운로드)]** 아이콘을 누르면 바탕화면에 단독 앱(PWA)이 설치됩니다!
- **📸 [스크린샷 삽입 위치 03]** (Publish 완료 화면 및 바탕화면 아이콘 캡처)

### 🔒 실습 및 사용 시 꿀팁 Q&A (오류/제약 사항 대처)

- **Q. AI가 엉뚱하게 코드를 고쳐서 화면이 깨졌어요!**
  - **A.** 당황하지 마시고 채팅창 우측의 **Undo(이전 대화 삭제)** 버튼을 누르면 직전 정상 상태로 돌아갑니다. 기능 수정 요청은 하나씩 천천히 대화하며 진행하세요.
- **Q. AI Studio 주소로 접속이 아예 안 돼요.**
  - **A.** 교육청 구글 계정(@o365.go.kr 등)은 보안 정책으로 접속이 차단될 수 있습니다. 반드시 **개인 구글 계정(@gmail.com)**으로 크롬에 로그인해 주세요.
- **Q. 카드 결제 등록(Billing)이 번거롭고 과금이 걱정돼요.**
  - **A.** 연동할 데이터베이스와 서버 배포용 구글 클라우드는 무료 범위(Free Tier) 내에서 평생 무료로 활용 가능합니다. 만약 카드 등록이 어렵다면 **배포하지 않고 AI Studio 우측의 [Preview] 패널 화면만으로도 실습과 소통이 가능**합니다.
- **Q. 바탕화면에 앱 다운로드(PWA) 아이콘이 안 보여요.**
  - **A.** 크롬 브라우저 우측 상단 **[점 3개 ➡️ 저장 및 공유 ➡️ 바로가기 만들기 (창으로 열기 필수 체크!)]**를 이용해 우회 설치해 보세요.
- **Q. 학교망 방화벽 때문에 주소 접속이 안 됩니다.**
  - **A.** 실습 시간 동안에는 스마트폰 핫스팟(테더링)을 임시로 연결해 해결하세요. 장기 사용을 위해선 정보부장님께 교육망 필터링 예외 처리를 요청하셔야 합니다.
